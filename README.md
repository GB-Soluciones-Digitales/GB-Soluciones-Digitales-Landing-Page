# GB Soluciones Digitales - Landing Page

Bienvenido al repositorio de la landing page corporativa de **GB Soluciones Digitales**. Este proyecto es una Single Page Application (SPA) moderna, rápida y responsiva, diseñada para presentar servicios tecnológicos.

![GB Soluciones Digitales Preview](/public/2.jpeg)
## 🚀 Tecnologías

Este proyecto está construido con el stack moderno de React + Vite:

* **[React 19](https://react.dev/)**: Biblioteca principal de UI.
* **[Vite](https://vitejs.dev/)**: Entorno de desarrollo ultrarrápido.
* **[Tailwind CSS v4](https://tailwindcss.com/)**: Framework de estilos "utility-first".
* **[Lucide React](https://lucide.dev/)**: Iconografía ligera y escalable.
* **[ESLint](https://eslint.org/)**: Linter para asegurar la calidad del código.

## 🛠️ Instalación y Configuración

Sigue estos pasos para correr el proyecto localmente:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/GB-Soluciones-Digitales/GB-Soluciones-Digitales-Landing-Page.git](https://github.com/GB-Soluciones-Digitales/GB-Soluciones-Digitales-Landing-Page.git)
    cd gb-soluciones-digitales
    ```

2.  **Instalar dependencias:**
    ```bash
    npm install
    ```

3.  **Iniciar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
    La aplicación estará disponible en `http://localhost:5173`.

4.  **Construir para producción:**
    ```bash
    npm run build
    ```

## 🎨 Estructura del Proyecto

